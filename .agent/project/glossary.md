# Glossary

- `delivery`: inbound transport adapters such as HTTP handlers and DTOs
- `app service`: application-layer orchestration for a use case
- `domain model`: core business entity or execution record
- `port`: interface that defines behavior required from infra
- `infra`: concrete implementation of ports and external integrations
- `scheduler runner`: process loop that discovers and executes due jobs
- `secret provider`: component that resolves plaintext or encrypted config values
