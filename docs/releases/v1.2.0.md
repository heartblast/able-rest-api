# v1.2.0 — Public Go module

## 주요 변경 사항

- Go module path를 `github.com/heartblast/able-rest-api`로 정상화했습니다.
- 외부 프로젝트가 REST 라우터, 업무 모듈, 미들웨어, OpenAPI JSON을 조립할 수 있도록 `framework` 공개 API를 추가했습니다.
- 공통 성공·오류 응답을 위한 `httpx` 패키지를 추가했습니다.
- 외부 consumer가 `internal/*`를 import하지 않고 `/api/v1/hello`와 `/openapi.json`을 제공할 수 있습니다.
- 공개 API의 설치·사용·검증 방법을 `AGENT_USAGE.md`에 추가했습니다.
- 기존 `cmd/server`, `cmd/scheduler`, user/mail API와 예약 메일의 동작을 유지합니다.

## 호환성 및 제한사항

- 이전 `able-rest-api/...` import 경로를 쓰는 소비자는 새 module path로 import를 변경해야 합니다.
- `framework.New()`는 이 저장소의 OpenAPI 문서를 기본으로 제공합니다. 자체 경로를 등록하는 consumer는 `SetOpenAPIJSON`으로 자신의 계약을 지정해야 합니다.
- 공개 프레임워크의 인증은 consumer가 `Use`로 설정해야 합니다. 기존 `cmd/server`의 API 키 보호는 유지됩니다.
- DB migration과 실제 SMTP·DB 연동의 운영상 제한은 [v1.1.0 릴리스 노트](v1.1.0.md)를 참고하세요.
