# v1.1.0 — Framework 1차 정식 릴리스

## 주요 변경 사항

- OpenAPI 3.0 문서를 `docs/openapi.yaml`의 단일 원본으로 관리하고 `/openapi.json`으로 제공합니다. 계약 버전을 1.1.0으로 올렸습니다.
- 런타임 응답 상태·스키마와 의미, 쓰기 작업의 부작용을 검증하는 계약 테스트를 추가했습니다. CI에서 `make openapi-check`를 실행합니다.
- HTTP 공통 기능과 업무 모듈을 분리하고 user, mail, scheduler 모듈의 모델·계약·서비스를 각 모듈로 옮겼습니다.
- PostgreSQL/MySQL에 영속 예약 메일 저장소를 추가했습니다. 원자적 claim, lease 만료 후 재claim, 동시 실행 제어, 지수 지연 retry와 시도 횟수 제한을 적용했습니다.
- 예약 메일의 Message-ID를 저장하고 재시도·재claim·프로세스 재시작 시 재사용해 중복 발송을 식별할 수 있게 했습니다.
- API 키 보호, JSON 요청 형식과 크기 제한, 메일 입력 검증, 운영 환경의 TLS·설정 파일 권한 검사를 강화했습니다.

## 운영 시 제한사항

- SMTP 수락 후 상태 기록 전에 장애가 나면 같은 Message-ID로 재발송될 수 있습니다. SMTP 또는 수신 서버의 exactly-once 전달은 보장하지 않습니다.
- DB migration은 배포 시 별도 도구나 DB 클라이언트로 번호 순서대로 적용해야 합니다. `cmd/migrate`는 SQL을 실행하지 않습니다.
- 실제 DB 어댑터는 PostgreSQL과 MySQL입니다. Oracle과 HSQLDB는 구현 스텁이며 이번 릴리스에서 검증된 지원 대상이 아닙니다.
- 계약 테스트는 실제 DB나 SMTP 없이 실행됩니다. 실제 DB migration 및 SMTP 전송은 배포 환경에서 별도로 검증해야 합니다.
